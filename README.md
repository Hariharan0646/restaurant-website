# 📖 About the Project

This project is a **Restaurant Website** developed using **HTML, CSS, JavaScript, php and MySQL**. It enables users to browse the restaurant menu, learn about the restaurant, contact the team, and reserve tables online through a simple reservation system.

The project focuses on responsive design, clean user experience, and basic backend integration for handling reservations.

---

# ✨ Features

- 🍔 Responsive Homepage
- 📋 Restaurant Menu
- 🏢 About Us Page
- 📞 Contact Page
- 📅 Online Table Reservation
- 🎨 Clean and Modern User Interface

# ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Hariharan0646/restaurant-website.git
```

### 2. Move the Project

Copy the project folder into:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Start:

- Apache
- MySQL

### 4. Import Database

Open:

```
http://localhost/phpmyadmin
```

Create the required database and import the SQL file (if available).

### 5. Run the Project

Open your browser and visit:

```
http://localhost/restaurant-website/
```
